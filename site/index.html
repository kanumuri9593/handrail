01 · How it works

One rule set, three moments.

Before the agent starts, while it works, and when it says it’s done. The same rules run on your laptop, in pre-commit, and in CI.

Before · scan

Catch risky setups

Reads agent instruction and config files in a repo or on your own machine.

handrail scan . --fail-on high
  • MCP autoApprove, bypassPermissions, Bash(*)
  • Keys committed in MCP configs
  • Agents in CI with approvals off, or on pull_request_target
  • Trojan-Source and invisible Unicode tag text
During · guard

Stop dangerous calls

A live Claude Code hook that checks every tool call before it runs.

handrail init claude --write
  • Blocks curl | bash, rm -rf /, exfiltration
  • Blocks an agent switching itself into bypass mode
  • Asks first before credential reads, pushes, deploys, test skips
After · audit

Check what it claimed

Reads the session transcript and compares claims with what actually ran.

handrail audit --latest
  • “All tests pass” with no passing run behind it
  • Success claimed right after a failure
  • Tests skipped without saying so; guardrail tampering

04 · For teams

      

        
Safe to roll out across an engineering org.

        
Developers are adding agent configs faster than security teams can review them. Handrail makes those files part of the normal review gate.

      

    

    

      
Nothing leaves your network
Runs entirely offline from the standard library. No telemetry, no API key, no SaaS account. Secret values are redacted in every output.

      
Low noise by design
Default rules are the ones that scored high on real repos. Noisy detectors stay opt-in, so a gate doesn’t train people to ignore it.

      
Fits your existing tools
SARIF for GitHub and Azure DevOps code scanning, JSON for your SIEM, exit codes for any pipeline, and an append-only audit log of agent tool calls.

    

    

      

        
Scan your own setup in ten seconds.

        
Run it on your laptop first. It checks ~/.claude, Claude Desktop, Cursor, Codex, Gemini and VS Code, and changes nothing.

      

      npx handrail-ai scan --home
