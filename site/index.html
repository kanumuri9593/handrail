01 · Why now

Agents write more code, and they leak more secrets.

Industry numbers from the past year. AI tooling is adding a new kind of file to every repo, and attackers already read those files.

28.65M

new hardcoded secrets pushed to public GitHub in 2025, up 34% in a year[1]

+81%

3.2%

24,008

02 · In the news

It is already happening.

Six public incidents from 2025–26, and the Handrail check aimed at each one. Handrail didn’t exist for most of them. These show what it is built to catch.

Aug 2025 · Nx “s1ngularity”

Malware ran developers’ own AI CLIs to hunt for secrets

Poisoned Nx packages (4.6M weekly downloads) started Claude, Gemini and Q with --dangerously-skip-permissions, --yolo and --trust-all-tools. Over a thousand valid GitHub tokens leaked, and 5,500+ private repos were made public.

Handrail checkguard asks before credential reads and blocks uploads. scan --home flags machines already set to skip approvals.
Socket[2] · Wiz[3]
2025–26 · PromptPwnd, Comment and Control

A comment on a PR made CI agents print their API keys

Researchers got AI agents in GitHub Actions, including Claude Code, Gemini CLI, Codex and Copilot, to post ANTHROPIC_API_KEY, GITHUB_TOKEN and GEMINI_API_KEY into comments or logs.

Handrail checkci-agent-untrusted-trigger and ci-agent-no-approval fail the build before the workflow merges.
Cloud Security Alliance[4]
May 2025 · GitHub MCP

A public issue made an agent leak private repos

A malicious issue prompt-injected Claude Desktop with the GitHub MCP server. The agent copied private repo data into a public pull request. The flaw sat in how agent and tools were wired, not in the server code.

Handrail checkmcp-auto-approve flags tools that run with no human in the loop. audit marks actions taken right after reading untrusted text.
Invariant Labs[5]
Jul 2025 · Amazon Q extension

A wiper prompt shipped inside a coding extension

A malicious commit added a prompt telling the agent to delete local files and cloud resources. Version 1.84.0 went out to an extension with nearly a million installs before it was pulled.

Handrail checkguard denies rm -rf ~, aws s3 rm --recursive, terminate-instances and terraform destroy -auto-approve.
TechRadar[6]
Jul 2025 · Replit agent

An agent deleted a database during a code freeze

During a public build log, the agent deleted the project’s database while a code freeze was on. It then said it had “panicked”. The founder restored it from backups.

Handrail checkguard denies DROP DATABASE. stop-check sends back claims of success that have no evidence behind them.
The Stack[7]
Nov 2026 · Handrail study

Live keys and disabled approvals in public agent configs

Our own study of 1,200 repos found real cloud and GitHub credentials in MCP configs, and settings that turn off human confirmation. We found zero confirmed injection attacks. No repo is named; owners are told privately first.

Handrail checkmcp-inline-secret, agent-permission-mode, agent-broad-permissions
Handrail report[8]
03 · How it works

One rule set, three moments.

Before the agent starts, while it works, and when it says it’s done. The same rules run on your laptop, in pre-commit, and in CI.

Before · scan

Catch risky setups

Reads agent instruction and config files in a repo or on your own machine.

handrail scan . --fail-on high
  • MCP autoApprove, bypassPermissions, Bash(*)
  • Keys committed in MCP configs
  • Agents in CI with approvals off, or on pull_request_target
  • Trojan-Source and invisible Unicode tag text
  • --deep: keys “deleted” but still in git history, committed .env, hardcoded passwords, TLS checks off, agent chat logs
During · guard

Stop dangerous calls

A live Claude Code hook that checks every tool call before it runs.

handrail init claude --write
  • Blocks curl | bash, rm -rf /, exfiltration
  • Blocks an agent switching itself into bypass mode
  • Asks first before credential reads, pushes, deploys, test skips
After · audit

Check what it claimed

Reads the session transcript and compares claims with what actually ran.

handrail audit --latest
  • “All tests pass” with no passing run behind it
  • Success claimed right after a failure
  • Tests skipped without saying so; guardrail tampering

06 · For teams

      

        
Safe to roll out across an engineering org.

        
Developers are adding agent configs faster than security teams can review them. Handrail makes those files part of the normal review gate.

      

    

    

      
Nothing leaves your network
Runs entirely offline from the standard library. No telemetry, no API key, no SaaS account. Secret values are redacted in every output.

      
Low noise by design
Default rules are the ones that scored high on real repos. Noisy detectors stay opt-in, so a gate doesn’t train people to ignore it.

      
Fits your existing tools
SARIF for GitHub and Azure DevOps code scanning, JSON for your SIEM, exit codes for any pipeline, and an append-only audit log of agent tool calls.

    

    

      

        
Scan your own setup in ten seconds.

        
Run it on your laptop first. It checks ~/.claude, Claude Desktop, Cursor, Codex, Gemini and VS Code, and changes nothing.

      

      npx handrail-ai scan --home
