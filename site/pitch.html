For engineering & security leads

Your developers gave AI agents shell access. Who reviewed the config?

Coding agents read files like .claude/settings.json, .vscode/mcp.json and AGENTS.md, then act on them. Those files can switch off approvals, auto-trust tool servers and hold live keys. Today they pass code review because nobody treats them as security-sensitive. Handrail does.

The problem

  • One line, defaultMode: bypassPermissions, removes the human from every agent action in that repo.
  • MCP configs auto-approve tools and carry tokens in plain text. We found real cloud and GitHub credentials in public ones.
  • Agents in CI run with approvals off, sometimes on untrusted pull requests that can reach repo secrets.
  • Agents report “all tests pass” after skipping them, and reviewers believe it.

What Handrail does

  • Before: scans repos and laptops for risky agent setups, and gates PRs in CI.
  • During: a live hook blocks remote-code runs, exfiltration and self-granted bypass mode, and asks before pushes and deploys.
  • After: audits session transcripts and flags claims with no evidence behind them.

Why security teams can approve it

  • Runs fully offline. No SaaS, no telemetry, no API key.
  • Secrets are redacted in every output.
  • Open source (MIT), Python standard library only, easy to audit.
  • Low noise: the core config rules scored 83–100% precision on hand-checked real repos. Rules that misfired are opt-in.

Fits the tools you already run

  • GitHub Actions, Azure DevOps, GitLab, Jenkins, pre-commit.
  • SARIF for code-scanning dashboards, JSON for your SIEM, exit codes for gates.
  • Covers Claude Code, Cursor, Copilot, Codex, Gemini, Windsurf and MCP.

A two-week pilot

  1. Run handrail scan across your org’s repos and a few laptops. Get a findings report in a day.
  2. Turn on the CI gate in report-only mode on 3–5 teams.
  3. Switch to --fail-on high and roll out the Claude Code guard.

The evidence behind it

A study of 1,200 randomly sampled active repos and 9,499 agent files, with precision and recall checked by hand. Plus a controlled test of whether Claude models follow instructions hidden in a repo: 0 of 54 did, and every finished run warned the user.
